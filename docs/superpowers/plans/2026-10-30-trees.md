# Trees Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Worldgen grows species of trees where their habitat lets them survive, written into the
terrain as log / branch / see-through leaf blocks. Chopping a trunk or branch detaches everything
of that tree beyond the cut into a dynamic rapier body that falls and disappears once at rest,
through a generic "detach terrain into a physics body" module.

**Architecture:** Worldgen gains habitat fields (forge rain + coast distance stored in the world
file; procedural stand-ins), a species table with niches, a pure order-independent placement
lattice and a fixed-point skeleton → block rasteriser; it writes tree blocks (tree id in
`Block.data`) into the surface band. `game` gains process-global block properties
(solid / cutout), `voxel_body.rs` (detach blocks → dynamic body with explicit mass, rest
detection, `Despawn` settle), and a `Chop` designation whose falling set is "every same-tree
component no longer connected to the tree's base". The client renders cutout leaves through a
separate alpha-tested pull pipeline and renders voxel bodies as brick children of an
interpolated entity.

**Tech Stack:** Rust stable 1.99.1; `worldgen` (no transcendental math), `game` (rapier 0.36 /
parry 0.31 forks, `libm`), Bevy 0.19.1 `client` (pulled-quad renderer, WGSL), Pillow for
generated textures.

**Spec:** `docs/superpowers/specs/2026-10-29-trees-investigation.md` (decisions at the top, §4–§7).
Current-code facts below were verified on `49074d0` (sim chunk 16³ blocks, cell mode removed,
`REGION_BLOCKS` dial).

## Review Focus

1. A tree straddling a chunk-column boundary is generated bit-identically whatever window asks
   (whole region vs. a sub-window of columns) — pinned in Task 5.
2. Chopping a tree whose crown touches a neighbour's crown leaves the neighbour completely
   untouched (different tree id) — pinned in Task 9.
3. A chop near a region edge never produces a body that leaves the region; a body whose centre
   does leave anyway is settled (despawned), never handed across the seam as a capsule — pinned
   in Tasks 7 and 9.
4. Rolling back the chop tick restores every cleared block, the colliders and the absence of the
   body bit-exactly (`hash(before) == hash(after undo)`) — pinned in Task 7.
5. Leaves are non-solid: a player / slime passes through a crown, the edit ray still hits a leaf
   block, and breaking a leaf still works — pinned in Task 1.
