# Prefabs 1 — building blocks and prefab core — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The game gains a set of building blocks, a catalogue of sub-block shapes, and a prefab module that reads prefab files, resolves them and lays them out chunk by chunk — with a built-in set and a command-line viewer. Nothing in the running game changes yet.

**Architecture:** Everything is new files in `crates/game/src/prefab/` plus data in `assets/`. A prefab has a *file form* (names, serde) and a *resolved form* (block ids, spatial buckets, column profile). One function, `layout_chunk`, turns a resolved prefab and a placement into the writes for one chunk; worldgen and runtime stamping will both call it in later plans.

**Tech Stack:** Rust (crate `game`, edition 2021), `ron` 0.12, `bincode`, `lz4_flex`, `crc32fast`; Python 3 + Pillow for textures (`tools/textures/gen.py`); `png` crate for the viewer.

**Spec:** `docs/superpowers/plans/2026-11-14-prefabs-minecraft-import-site-generation.md` (the roadmap; this plan is its stages A and B).

- Never write a chunk or region edge as a literal: use `game::CHUNK_BLOCKS`, `game::BLOCK_VOXELS`. Tests run at `CHUNK_BLOCKS` = 16 but must not assume it.

- Minecraft names appear only as our own block *names* where they are generic words (`smooth_sandstone`, `oak_planks`).

## Review Focus

- A prefab file with a palette index, box or shaped cell outside its declared `size` → `resolve` returns a `Problem`, never panics or writes out of range (Task 4).
- A `.prefab.bin` that is truncated, has a wrong magic, or declares a decompressed length of gigabytes → refused before allocating (Task 3).
- A placement at negative world coordinates, or one whose bounds straddle a chunk edge on all three axes → every cell lands in exactly one chunk's stamp (Task 5).
- A prefab far larger than a chunk (600 × 200 × 600, one box) → `layout_chunk` for one chunk returns promptly and reads only that chunk's share (Tasks 4, 5).
- A shape placed with a turn and a mirror → identical to the pre-turned, pre-mirrored shape placed plainly; stairs do not come out left-handed (Tasks 2, 5).

```rust
// turn.rs — the one rotation convention. +X is east, +Z is south, north is −Z.
/// One quarter turn clockwise seen from above maps (x, z) -> (-z, x): north -> east.
pub fn turn_xz(x: i32, z: i32, quarter_turns: u8) -> (i32, i32);      // turns taken mod 4
pub fn turn_voxel(v: [usize; 3], quarter_turns: u8) -> [usize; 3];    // inside a 16³ block: (x,z) -> (15-z, x)

// shapes.rs — all derive Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Serialize, Deserialize
pub enum Facing { North, East, South, West }
pub enum Half { Bottom, Top }
pub enum StairCorner { Straight, InnerLeft, InnerRight, OuterLeft, OuterRight }
pub struct Sides { pub north: bool, pub east: bool, pub south: bool, pub west: bool }   // serde default false each
pub enum Shape {
    Slab { half: Half },
    Stairs { facing: Facing, half: Half, corner: StairCorner },
    Wall { sides: Sides, post: bool },
    Fence { sides: Sides },
    Pane { sides: Sides },
    Trapdoor { facing: Facing, half: Half, open: bool },
    Carpet,
    Layer { layers: u8 },          // 1..=8
}
impl Shape {
    pub fn is_valid(self) -> bool;                       // false only for Layer outside 1..=8
    pub fn filled(self, x: usize, y: usize, z: usize) -> bool;   // voxel occupancy, 0..BLOCK_VOXELS each
    pub fn turned(self, quarter_turns: u8) -> Shape;
    pub fn mirrored_x(self) -> Shape;                    // reflect x -> 15 - x
    pub fn chisel(self, material: BlockId) -> ChiselData;        // via ChiselData::from_fn, canonical
}
```

Geometry (voxels, `H = BLOCK_VOXELS / 2 = 8`; write the numbers in terms of `BLOCK_VOXELS`):
- `Slab`: bottom `y < 8`, top `y >= 8`.
- `Stairs`, `half: Bottom`, `facing: North`: the slab `y < 8` plus an upper part in `y >= 8`. `facing` is the side of the full-height back. Left and right are as seen looking toward `facing` (facing north: left = west = low x). Upper part: `Straight` `z < 8`; `OuterLeft` `x < 8 && z < 8`; `OuterRight` `x >= 8 && z < 8`; `InnerLeft` `z < 8 || x < 8`; `InnerRight` `z < 8 || x >= 8`. `half: Top` mirrors y. Other facings are the north shape turned.
- `Fence`: post `6 <= x,z < 10`, full height; per set side two rails 2 wide (`7..9` across), `y` in `6..9` and `12..15`, from the post to that edge.
- `Wall`: `post` → `4 <= x,z < 12` full height; per set side an arm `5..11` across, `y < 14`, from the centre to that edge. No post and no sides is an empty shape (allowed).
- `Pane`: per set side a sheet `7..9` across, full height, from the centre to that edge; with no sides, the post `7 <= x,z < 9`.
- `Trapdoor`: closed → 3 voxels thick, `y < 3` (bottom) or `y >= 13` (top); open → 3 thick against the side **opposite** `facing`, full height (facing north → `z >= 13`).
- `Carpet`: `y < 1`. `Layer { layers }`: `y < 2 * layers`.

```rust
pub enum Trust { Builtin, Untrusted }
pub const UNTRUSTED_MAX_EXTENT: u32 = 256;      // per axis
pub const UNTRUSTED_MAX_ITEMS: usize = 65_536;  // boxes + shaped + carve + markers
pub const PREFAB_BUCKET_BLOCKS: i32 = 16;       // the spatial index's cell; a prefab-internal constant, not CHUNK_BLOCKS

pub enum Problem {                               // Debug, Clone, PartialEq, Eq, Display
    BadFormat(u16), EmptyName, EmptySize, UnknownBlock(String),
    BadPaletteIndex { list: &'static str, index: usize },
    OutsideSize { list: &'static str, index: usize },
    BadShape { index: usize }, DuplicateShaped { at: [i32; 3] },
    BadTurn { index: usize }, TooLarge { what: &'static str, limit: usize },
}
/// What one cell of a prefab holds. Precedence, lowest first: Keep, carve boxes, boxes in file order
/// (a later box wins), shaped cells.
pub enum Cell<'a> { Keep, Carve, Block(BlockId), Shaped(&'a ResolvedShape) }
pub enum ResolvedShape { Named { shape: Shape, mat: BlockId }, Cuboids { cuboids: Vec<([u8; 3], [u8; 3], u8)>, mats: Vec<BlockId> } }
pub struct ResolvedPrefab {                      // Debug, Clone, PartialEq
    pub name: String, pub name_key: u32, pub meta: PrefabMeta,
    pub size: [u32; 3], pub anchor: [i32; 3], pub ground: GroundFit, pub tags: Vec<String>, pub markers: Vec<Marker>,
    /* private: palette ids, boxes, shaped, carve, buckets: BTreeMap<[i32; 3], Bucket>, profile */
}
pub fn prefab_name_key(name: &str) -> u32;       // crc32fast of the UTF-8 name
pub fn resolve(file: &PrefabFile, block_named: &dyn Fn(&str) -> Option<BlockId>, trust: Trust) -> Result<ResolvedPrefab, Vec<Problem>>;
impl ResolvedPrefab {
    pub fn cell(&self, at: [i32; 3]) -> Cell<'_>;                         // Keep outside 0..size
    /// Every non-Keep cell with min <= cell < max (clamped to the prefab), in ascending (z, y, x) order.
    /// Cost is bounded by the buckets the range overlaps, not by the prefab.
    pub fn for_each_cell(&self, min: [i32; 3], max: [i32; 3], f: &mut dyn FnMut([i32; 3], Cell<'_>));
```
